# ResViz

Web app that parses a propositional-logic knowledge base, converts it to
CNF, and runs a priority-based resolution algorithm — visualising the
derivation as a step-forward/backward debugger, so the Learner Admissions
committee can see how a satisfiability conclusion was reached instead of
doing it by hand.

Team: West Coast Vikings (CSC3003S capstone).
